# A8 — consolider TRAME Research Lab sans fabriquer de preuve financière

**25 octobre 2026.** Cette phase complète le démonstrateur synthétique
`research/trame_lab/cli.py`, sans changer ses expériences historiques
ni rendre une décision de trading. La nouvelle CLI
`research/trame_lab/evidence.py` sert à **relire** des rapports produits
par d'autres sous-projets, pas à les recalculer.

## Utiliser la CLI sans dépendances de calcul scientifique

Depuis la racine du dépôt, avec Python 3.12, et **uniquement**
sur des fichiers JSON de recherche déjà présents localement :

```powershell
python -m research.trame_lab.evidence --input synthetic_a3c_cpu.json synthetic_a3c_proxy_budget.json --output trame_evidence.html
```

Deux fichiers sont créés : `trame_evidence.html` et
`trame_evidence.json`. Le contenu et la chaîne de champs
ont été validés, les noms d'architecture sont échappés,
les empreintes SHA-256 conservent la trace des données importées.
Un fichier existant n'est **pas** remplacé sans `--overwrite`.
Les fichiers sont préparés avant remplacement ; la paire
HTML/JSON **n'est pas une transaction atomique**, notamment
en cas de coupure entre deux renommages.

Tests unitaires :

```powershell
python -m unittest research.trame_lab.test_evidence -v
```

## Limites à ne pas oublier

- Les fichiers JSON de recherche ne sont **pas** signés ;
  `source_authenticity_independently_verified=False` toujours.
- Les nombres synthétiques et les coûts partiellement comptés
  n'autorisent aucun verdict financier.
- L'acceptation d'un rapport exploratoire BTC ne constitue
  ni validation de son origine, ni test indépendant, ni
  preuve de rentabilité, ni autorisation de redistribuer
  les historiques privés.
- Les métriques de coût, NLL et MAE ne sont **pas**
  normalisées pour un graphique de classement global.
- Le rapport est un outil de revue locale **read-only**.
  Il n'appelle ni broker, ni modèle, ni API, ni téléchargement.
- Les phases A4/A6 (GPU Mamba / checkpoints zero-shot)
  et A7 (exécution financière réelle) ont leurs propres
  portes de validation, dont plusieurs restent fermées.

## Dépendances de branches à ne pas fusionner aveuglément

Le développement A8 se trouve sur
`chatgpt/trame-research-lab-evidence-20261025`, branché
sur PR #10 (A3c), elle-même empilée sur PR #9 et PR #8.
Les PR expérimentales #11 (Mamba), #12 (hybride),
#13 (foundation) et #14 (baselines BTC) sont des
**branches sœurs** ; ne pas prétendre que leurs fichiers
font partie d'A8 sans les avoir fusionnés explicitement.
La CLI A8 n'en dépend pas à l'import : elle traite
leurs JSON locaux **si ceux-ci sont réellement fournis**.
