# Validation technique sans revendication financière

Cette CI exécute uniquement les tests synthétiques préexistants de
`research/trame_poc0/test_research.py`.

- Aucun jeu de données de marché, protocole gelé, rapport scientifique ou résultat de backtest n'est modifié.
- Une réussite atteste la stabilité des fonctions testées, pas un pouvoir prédictif, une rentabilité ni une validation hors échantillon.
- Les dépendances se limitent à Python et NumPy; aucun accès à un compte de trading.
- Le résultat GitHub Actions doit être consulté après ouverture de PR: tests non exécutés ici.

Voir `AGENTS.md` et `docs/CHATGPT_PROJECT_HISTORY.md` avant toute modification.
